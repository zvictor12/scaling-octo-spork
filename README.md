# Динамика скопления амёб

Модель А. А. Самарского и А. П. Михайлова, «Математическое моделирование: идеи, методы, примеры», гл. IV, §1, с. 136–140. Амёбы выделяют вещество и движутся туда, где его больше. Диффузия, наоборот, размывает скопления.

## Задача

В книге дана одномерная система:

$$
N_t=\frac{\partial}{\partial x}(\mu N_x-\eta N\rho_x),\qquad
\rho_t=D\rho_{xx}+\alpha N-\beta\rho.
$$

$N$ — концентрация амёб, $\rho$ — концентрация вещества. $\mu$ и $D$ отвечают за диффузию, $\eta$ — за движение к веществу, $\alpha$ — за его выделение, $\beta$ — за распад. Для постоянного состояния потоки исчезают, а $\alpha N_*-\beta\rho_*=0$, то есть $\rho_*=\alpha N_*/\beta$. Любое постоянное $N_*$ подходит: его задаёт общее количество амёб.

Мы перенесли ту же идею на квадрат $[0,L]^2$: вместо производной по $x$ берём градиент и лапласиан.

$$
N_t=\nabla\cdot(\mu\nabla N-\eta N\nabla\rho),\qquad
\rho_t=D\Delta\rho+\alpha N-\beta\rho.
$$

Через четыре стороны квадрата амёбы и вещество не проходят: нормальные потоки там равны нулю. Это тоже наше условие для численного опыта.

## Что задаёт начальное состояние

В [config.yaml](config.yaml) поля `initial_n` и `initial_rho` — **формулы**, которые SymPy разбирает, а NumPy вычисляет в центрах ячеек. Можно использовать `x`, `y`, `pi`, параметры конфига и функции `sin`, `cos`, `exp`, `sqrt`, `Abs`. В конфиге `n0` задаёт базовый уровень в предложенных формулах, а `epsilon` — величину возмущения. Сейчас `initial_rho` равно `alpha*n0/beta`, но его тоже можно заменить своей формулой. Для расчёта равновесия программа берёт $N_*$ как среднее начального поля $N$ и затем вычисляет $\rho_*=\alpha N_*/\beta$. У трёх готовых опытов это среднее равно `n0`.

- Опыт 1 задаёт формулой $N(x,y,0)=N_0[1+\varepsilon(\cos(\pi x/L)+\cos(\pi y/L))/2]$. Это две первые пространственные моды, по $x$ и по $y$.
- В опытах 2 и 3 формула `n0*(1 + epsilon*noise)`. Переменная `noise` — случайное поле, сглаженное гауссовым фильтром с шириной `sigma` **в ячейках**, с нулевым средним и максимальным модулем 1. `seed` фиксирует поле: при сравнении двух `eta` старт одинаковый.

Формулу можно поменять на любую комбинацию этих переменных и функций, например `n0*(1 + epsilon*sin(2*pi*x/length)*cos(pi*y/length))`. Доступны арифметические операции `+`, `-`, `*`, `/`, `**`; произвольный код Python в формулах не выполняется. `cells` — число ячеек вдоль **каждой** стороны; всего ячеек `cells²`. У шума есть много пространственных мод сразу, поэтому не стоит ждать, что всё поле будет расти как одна экспонента.

## Как считаем

Разбиваем квадрат на ячейки со стороной $h=L/m$. Между соседними ячейками по $x$ скорость движения к веществу равна $v^x=\eta(\rho_{i+1,j}-\rho_{ij})/h$. Поток амёб через эту грань:

$$
J^x_{i+1/2,j}=-\mu\frac{N_{i+1,j}-N_{ij}}{h}
+\max(v^x,0)N_{ij}+\min(v^x,0)N_{i+1,j}.
$$

Если поток идёт вправо, берём $N$ слева; если влево — справа. По $y$ делаем ровно так же. Из разности потоков через четыре грани получаем скорость изменения $N$ в ячейке:

$$
\dot N_{ij}=-\frac{J^x_{i+1/2,j}-J^x_{i-1/2,j}
+J^y_{i,j+1/2}-J^y_{i,j-1/2}}{h}.
$$

Для $\rho$ используем обычные разности по обеим осям и добавляем $\alpha N_{ij}-\beta\rho_{ij}$. Так PDE превращается в $2m^2$ ОДУ. Их решает `solve_ivp` методом **BDF**. На границах потоки ставим нулевыми. Дискретизация направленного потока помогает сохранить неотрицательность; после численного решения минимум обеих концентраций записывается в отчёт, без обрезания значений.

## Когда неоднородность растёт

Сначала книжный расчёт в одном измерении. Пишем $N=N_0+u$, $\rho=\rho_0+v$, где $\rho_0=\alpha N_0/\beta$, а $u,v$ малы. Здесь $N_0$ — концентрация выбранного постоянного состояния; для наших расчётов это $N_*$. Отбрасываем произведение $uv_x$ и получаем

$$
u_t=\mu u_{xx}-\eta N_0v_{xx},\qquad
v_t=Dv_{xx}+\alpha u-\beta v.
$$

Подставляем $u=Ae^{\gamma t}\cos(kx)$ и $v=Be^{\gamma t}\cos(kx)$. Ненулевые $A,B$ возможны, если определитель матрицы равен нулю:

$$
\det\begin{pmatrix}
\gamma+\mu k^2 & -\eta N_0k^2\\
-\alpha & \gamma+\beta+Dk^2
\end{pmatrix}=0.
$$

Отсюда $\gamma^2+b\gamma+c=0$, где $b=\beta+k^2(\mu+D)$ и $c=k^2[\mu(\beta+Dk^2)-\eta\alpha N_0]$. $\gamma$ — показатель роста: положительный означает рост. В квадрате разрешённые моды имеют номера $(n_x,n_y)$ и $k^2=\pi^2(n_x^2+n_y^2)/L^2$. Это продолжение того же расчёта на две координаты. Для каждой ненулевой моды условие затухания:

$$
\mu(\beta+Dk^2)>\eta\alpha N_0.
$$

В отчёте и на двух панелях статичного графика даны **непрерывные** собственные значения для мод $(1,0)$ и $(0,1)$. Их значения совпадают: квадрат одинаков по обеим осям. Для шума это лишь ориентир: остальные моды тоже присутствуют. Нулевая мода меняет общий уровень и к росту пространственной неоднородности не относится.

## Запуск

В [config.yaml](config.yaml) три опыта. Общие коэффициенты лежат в `common`, а у каждого номера свои `eta` (два сравниваемых значения), `epsilon`, формула `initial_n`, время `t_end` и настройки анимации. Параметры отдельного опыта заменяют общие. Для шума заданы `sigma`, `seed` и более мелкая сетка.

```bash
uv sync --extra test
uv run --extra test pytest
uv run amoeba-experiments 1
uv run amoeba-experiments 2
uv run amoeba-experiments 3
```

Один запуск считает **один номер** и открывает окно с картами $N$ и $\rho$ для двух значений `eta`. После закрытия окна расчёт закончен. Статичный график `eigenvalues.png` и `report.json` лежат в `figures/experiment_НОМЕР/`; карты на диск не записываются.

В `report.json` есть использованные настройки, вычисленные `equilibrium_n` и `equilibrium_rho`, непрерывные собственные значения обеих мод для каждого `eta`, минимумы $N$ и $\rho$, и `nfev` — сколько раз BDF вычислил правую часть. Старых графиков амплитуд и проверки массы здесь нет. Схема на сетке сглаживает резкие пики, а BDF даёт небольшую временную погрешность; для чувствительного результата можно увеличить `cells` и сравнить картинки.
